Assess diversity of the PCV data set

Shaoqian Huang

2026-09-17

Aims

The document aims to apply the proposed model-based assessment of diversity on the percentage cover value (PCV) data set and compare the proposed approach with randomized Rao’s Q.

In order to simplify the modelling the process, I keep the species whose absence rate is lower than \(55\%\), so there are 12 out of 296 species are left.

Filter community data by removing rare species

# Keep species missing in less than rare_threshold of plots.
zero_threshold <- 0.55
zero_prop <- colMeans(
  my.sample == 0,
  na.rm = TRUE
)

my.sample.filtered <- my.sample %>%
  select(
    where(~ TRUE)
  )

# Apply the occurrence filter only to species columns.
species_columns <- colnames(my.sample)[-c(1, 2)]

species_to_keep <- species_columns[
  zero_prop[species_columns] <= zero_threshold 
]

my.sample.filtered <- my.sample %>%
  select(
    all_of(colnames(my.sample)[1:2]),
    all_of(species_to_keep)
  )


# Species retained for the model.
selected_species <- colnames(
  my.sample.filtered
)[-c(1, 2)]

# The number if species retained for the model
p <- length(selected_species)

Species present more than 45% of all the plots are kept.

Convert community data to long format

yX <- reshape(
  my.sample.filtered,
  direction = "long",
  varying = selected_species,
  v.names = "y",
  timevar = "sp",
  times = selected_species
)

# Convert grouping variables to factors.
yX[c("sp", "Site", "Community", "id")] <-
  lapply(
    yX[c("sp", "Site", "Community", "id")],
    factor
  )

# Convert percentage cover to proportions.
yX$y <- yX$y / 100

# ordBeta requires values strictly between 0 and 1.
yX$y[yX$y >= 1] <- 0.9999

Distance and Similarity Matrices

# Keep only species present in the filtered community dataset.
subtree <- keep.tip(
  tree,
  selected_species
)
# Replace species labels
subtree_plot <- subtree
subtree_plot$tip.label <- paste0("sp", seq_along(subtree_plot$tip.label))

plot(subtree_plot)

# Phylogenetic distance matrix.
DM_phy_func <- cophenetic.phylo(subtree)


# Convert distance to a similarity-like matrix.
VC_phy_func <- max(DM_phy_func) - DM_phy_func


# Project the similarity matrix onto the centred subspace

J <- diag(p) -
  (1 / p) * matrix(1, p, p)


VC_phy_func_J <- J %*%
  VC_phy_func %*%
  J

V_J <- eigen(VC_phy_func_J)$vectors
D_J <- eigen(VC_phy_func_J)$values

\(\boldsymbol{V}_J\) is the eigenvector matrix of \(\boldsymbol{S}_J\). Column space of \(\boldsymbol{V}_J\) strategically represents \(\boldsymbol{R}^{p}\) as \(\boldsymbol{1}^{\perp} \oplus \boldsymbol{1}\), where the former is the relative abundance space and latter is the total abundance space.

Diversity Assessment

Extract fixed and random effects

## Estimates of fixed effects, eta_T
eta_T_hat <- predict(model, 
                   type = "link",
                   re.form = NA)

# Arrange eta_T_hat into a matrix
eta_T_hat <- matrix(
  as.numeric(eta_T_hat),
  ncol = p,
  byrow = FALSE
)

# Estimates of row centered fixed effects, eta_B 
eta_B_hat <- eta_T_hat %*% J 

##  Estimates of conditional random effects on y
RR <- simulate_random_effects(model = model, uncertainty = TRUE)

Dose \(\hat{\mu}_B^{\top}D\hat{\mu}_B\) can measure diversity correctly?

## Randomized Rao's Q diversity for reference
# Ensure that the abundance matrix has the same species and ordering as the
