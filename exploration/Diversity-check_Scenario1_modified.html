Model-based diversity measure and plot checking

Shaoqian Huang

2026-09-10

Aims

The document aims to check (1) if \(\hat{\mu}_B^{\top}D\hat{\mu}_B\) can measure diversity correctly? \(\hat{\mu}_B = g^{-1}(\hat{\eta}_B)\). (2) if we can project \(\hat{\eta}_B\) onto the first two axes of \(JSJ\) to visualize how relative abundance changes along gradients in a biplot.

Based on David’s experiment, here I adopt Scenario 1 where there are 6 communities. Specifically, com 1 and com 2 have the same diversity, com 3 and com 4 decreases in diversity compared with com 1, com 5 retains the same level diversity as com 1 but decreases in overall abundance, and com 6 increases in diversity compared with com 1.

Produce mean abundances with correlations

## Mean abundance matrix
# Expand mu across sites
mu_site <- mu[rep(c(1 : q), each = r), ] 

# Calculate variance and covariance matrix of u
S <- max(D) - D 
mean <- rep(0, p)
sigma <- S

# Generate r * p multivariate normal samples
resi_corr <- rmvnorm(n = r * q, mean = mean, sigma = sigma) 

# Linear predictors 
eta_u_site <- logit(mu_site) + resi_corr

I set the similarity matrix \(S\) as the variance-covariance matrix of \(u\), which induces correlations for multivariate GLM.

Data Generation

## Abundance matrix
abundance <- mu_eta_u_site
abundance[] <- rbinom(length(mu_eta_u_site), size = 1, prob = mu_eta_u_site)

# Create community factor (1:q repeated r times each)
com <- factor(rep(1:q, each=r))

# Combine abundance matrix and community labels into a data frame
yX <- data.frame(abundance, com)

## Long format abundance data
yX <- reshape(yX, direction = "long", varying = colnames(abundance),
              v.names = "y", timevar = "sp")

# Convert species column to factor
yX$sp <- factor(yX$sp)

Modelling

model <- glmmTMB (y ~ com * sp + rr(sp + 0 | id, 2),
                  family = 'binomial',
                  data = yX)

Model-based Diversity Assessment

Extract fixed and random effects

## Estimates of fixed effects, eta_T
eta_T_hat <- predict(model, 
                   type = "link",
                   re.form = NA)

# Arrange eta_T_hat into a matrix
eta_T_hat <- matrix(
  as.numeric(eta_T_hat),
  ncol = p,
  byrow = FALSE
)

# Estimates of row centered fixed effects, eta_B 
eta_B_hat <- eta_T_hat %*% J 

##  Estimates of conditional random effects on y
RR <- simulate_random_effects(model = model)

Dose \(\hat{\mu}_B^{\top}D\hat{\mu}_B\) can measure diversity correctly?

## True diversity for reference
Div_TRUE <- rowSums(expit(eta %*% J) %*% D * expit(eta %*% J))
print(Div_TRUE)
##        1        2        3        4        5        6 
## 15.53312 15.53312 14.64182 10.88779 15.53312 16.61324
## Model-based diversity
Div_Model <- rowSums(expit(unique(eta_B_hat)) %*% D * expit(unique(eta_B_hat)))
print(Div_Model)
## [1] 15.28924 14.60086 14.42290 11.51594 15.47442 16.32854

The results show the comparison of \(\mu_B^{\top}D\mu_B\) and \(\hat{\mu}_B^{\top}D\hat{\mu}_B\). Except for variation caused by estimation, \(\hat{\mu}_B^{\top}D\hat{\mu}_B\) satisfies the expectation that diversity keeps the same between com 1 and com 2, decreases gradually through com 3 and com 4, keeps the same at com 5 with com 1 by accounting overall abundance change, and increases at com 6 compared with com 1.

## Produce boxplot for model-based diversity in each com 
# Model-based Diversity Assessment 
mu_eta_B_u_hat <- eta_B_hat + RR 
Div_Model <-  rowSums(mu_eta_B_u_hat %*% D * mu_eta_B_u_hat)
Div_Model_data <- data.frame(
  group = com,
  value = Div_Model
)
Boxplot(data = Div_Model_data,
        group_levels = c(
          '1',
          '2',
          '3',
          '4',
          '5',
          '6'),
        ylab = "mu_B^{T}Dmu_B"
        )

The boxplots plot \(\hat{\mu}_B D \hat{\mu}_B\) by adding samples from \(u|y\), which shows the exact diversities as true diversities, which implies that \(\hat{\mu}_B D \hat{\mu}_B\) can measure diversity when we are studying relative abundance.

Can we project \(\hat{\eta}_B + \hat{u}|y\) onto the first two axes of \(JSJ\) to visualize how relative abundance changes along gradients in a biplot?

## Produce a biplot based on \eta + u (true parameters)
Biplot(abundance = cbind(com, eta_u_site), P = eigen(J %*% S %*% J)$vectors, plot_labs = labs(
  x = expression(v[J1]^T * eta[B]),
  y = expression(v[J2]^T * eta[B])
))

## Produce a biplot based on estimate of \eta_B + u (Estimate \eta_B and u)
eta_T_u_hat  <-  eta_T_hat + RR
colnames(eta_T_u_hat) <- LETTERS[1:5]
Biplot(abundance = cbind(com, eta_T_u_hat + RR), P = eigen(J %*% S %*% J)$vectors, plot_labs = labs(
  x = expression(v[J1]^T * (hat(eta[B]) + hat(u) * "|" * y)),
  y = expression(v[J2]^T * (hat(eta[B]) + hat(u) * "|" * y))
))

## Produce biplot to project \eta_B_hat + u (Only estimate \eta_B). 
eta_T_hat_u <- eta_T_hat + resi_corr
colnames(eta_T_hat_u) <- LETTERS[1:5]
Biplot(abundance = cbind(com, eta_T_hat_u), P = eigen(J %*% S %*% J)$vectors, plot_labs = labs(
  x = expression(v[J1]^T * (hat(eta[B]) + u)),
  y = expression(v[J2]^T * (hat(eta[B]) + u))
))

The first biplot shows the projection of real parameters \(\eta + u\) on \(v_J1\) and \(v_J2\), which is as the expectation. The second biplot shows the projection of estimates of \(\eta + u\) on \(v_J1\) and \(v_J2\). The estimator is \(\hat{\eta}_T + \hat{u}|y\). The difference with expectation is the distribution of the points in each com, where we use a posterior distribution in the estimator. In order to check if the difference of the two plots is caused by using \(\hat{u}|y\) in \(\hat{\eta}_T + \hat{u}|y\), I produce a biplot to project \(\hat{\eta}_T + u\) by changing \(\hat{u}|y\) to \(u\) in \(\hat{\eta}_T + \hat{u}|y\), which is shown in the third biplot.

Conclusions

  1. \(\hat{\mu}_B^{\top}D\hat{\mu}_B\) can measure diversity correctly.
  2. We can project \(\hat{\eta}_B\) onto the first two axes of \(JSJ\) to visualize how relative abundance changes along gradients in a biplot.
